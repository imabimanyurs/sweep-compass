# Sweep Compass

Interactive NQ session scenario explorer. Select the overnight Asia/London pattern, mark London levels already broken after 08:00 ET, and apply an optional higher-timeframe trend overlay.

## Run

Open `index.html` in a browser. No installation or build is required. Fonts load from Google Fonts when available, with local fallbacks.

## GitHub Pages

In the repository's Settings → Pages, select **Deploy from a branch**, then **main** and **/(root)**. Save. GitHub supplies the live URL when deployment completes. Asset links are relative, so project Pages URLs work without changes.

## Data

Source: https://nqstats.com/aln_sessions — published NQ study of 2,542 sessions, 2016–2025. Rates are transcribed, not independently validated. The source's aggregates and conditional figures do not fully reconcile; this is disclosed in the interface. Higher-timeframe trend and current price location do not modify the probabilities. No market feed or trade execution is included.

The study's New York window begins at 08:00 ET, not the 09:30 cash open. Historical frequencies are not guaranteed forecasts or trade recommendations.
